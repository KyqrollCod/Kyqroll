# Clear Horizon — 15秒ループ

![Contact sheet](contact-sheet.jpg)

夏の空から風に乗って海面をかすめ、海に潜り、水面を突き抜けて空へ戻る、15 秒のシームレスループ。海と空と風を、点と線と図形だけで描いています。[ショーリール](../showreel/)の HUD とドットのビジュアル言語を引き継いでいます。

- **[`clear-horizon.mp4`](clear-horizon.mp4)** — 完成版。1920×1080 / 60p / H.264 + AAC 320kbps / 15.000 秒 / -16 LUFS。プレイヤーのループ再生でつなぎ目なく回ります
- **`index.html`** — エンジン本体。ブラウザで開くとリアルタイムでループ再生・スクラブができます
- **`render.mjs`** — 書き出しスクリプト（ショーリールと同じ仕組み）

## 色

参考画像（白が主役の、明るい海辺の部屋）から取りました。

| 役割 | 色 |
|---|---|
| 空 | アジュール `#2E9CF0` → 水色 `#78C8F8` → 淡い空色 `#CDEEFF` → 白い霞 |
| 海 | 水平線の深い青 `#1D6FD1` → アジュール → ターコイズ `#3BD0E9` → 淡いアクア `#A5F0F4` |
| 水中 | 水面の明るいアクア → `#1C86DE` → 深い青 `#1350B9` |
| 光・泡・雲 | 白 |
| 差し色 | ラベンダー `#B8B0F5`（風のリボン、雲の影、魚）、太陽だけ淡い黄色 `#FFF3B5` |

## 動き（96 BPM × 6小節 = 15秒）

| 時間 | カメラ | 見えるもの |
|---|---|---|
| 0–2.5 秒 | 上空。水平線は下寄りで、-9° 傾いている | 太陽とリング、流れる雲、風のリボン |
| 2.5–5 秒 | 急降下しながら +12° までロール、ズームイン、加速 | 点の海が手前へ流れ込む、放射状のスピードライン |
| 5–7.5 秒 | 海面をかすめ、ダイブ | 水面が波打つ線で画面を分割しながら上へ抜ける、しぶき |
| 7.5–10 秒 | 水中で、水面を下から見上げる | 裏側から見た点の海、光の柱、泡、ラベンダーの魚群、水中の流れ |
| 10–12.5 秒 | 急上昇して、水面を突き抜ける | 泡が一気に下へ流れる、水面の線が下へ抜ける、しぶき |
| 12.5–15 秒 | 上空へ戻り、開始時の構図に戻る | 風のリボン、雲、太陽 |

- **カメラ**：高さ、水平線の位置、ロール、焦点距離、前進速度、横揺れの 6 つを、半小節ごとのキーから周期的な Catmull-Rom スプラインでつないでいます。ループ点では位置だけでなく速度もつながります。小節の頭ごとに小さくズームパンチが入ります
- **海**：前進する点のフィールド（遠近法）です。波の z 方向の波数を「1ループで進む距離」の整数分の一にしているので、15 秒後には海がまったく同じ位置に戻ります
- **風**：カーテンのような半透明のリボンが、はためき、裏返りながら斜めに横切ります（表は白、裏はラベンダー）。その横に細い風の線が 2 本並走します。舞う粒子、3 層で流れる雲も風を表しています
- **音**：ベル系の 16 分音符アルペジオの 1 音ごとに、海面にきらめきが 1 つ出ます。カメラの速度に合わせて風切り音が強くなり、リボンにはウーッシュ音が付きます。潜っている間はミックス全体にローパスがかかってこもり、水面を突き抜けた瞬間に開きます

## シームレスループの検証

- **映像**：フル書き出しのフレーム 0 と、単独で描いたフレーム 900 を画素単位で比べ、タイムコードの文字以外は完全に一致しました
- **音**：3 周分をレンダリングして中央の 1 周を使っています。ループ末尾の 3 秒は、前の周の同じ区間と 1e-6 以下の差しかありません。つなぎ目でプチッという音は出ません
- canvas のストローク状態をフレームごとにリセットし、破線のオフセットやイベントの経過時間もすべて 1 周期内に折り返しています

## 書き出し

```bash
cd clear-horizon
npm install
FFMPEG=/path/to/ffmpeg node render.mjs                         # → out/clear-horizon.mp4（4ワーカーで約2.5分）
FFMPEG=/path/to/ffmpeg node render.mjs --stills 0,400,860      # 確認用の静止画
```
