# プロフィール文（下書き）

公開時にココナラの欄と文字数上限に合わせて調整し、実際に反映した文面をここに上書きする。
経歴・資格・実績はオーナーから聞いた事実だけを書く。分からないものは書かない（規約第18条1項5号: 虚偽表示の禁止）。
表示名・アイコンは、既存アカウントに実績やレビューが付いていれば変えない（積み上げを失うため）。付いていなければ、
LP制作に合う表示名とアイコンに変えてよい。アイコンは顔写真でなくてよい（シンプルなロゴ風の図形）。

**キャッチフレーズ**
講師・コーチ・教室の「体験申込LP」を、通話なし・72時間で。

**自己紹介**
はじめまして。個人の講師・コーチ・教室の方に向けて、体験レッスンや無料相談の申込ページ（LP）を作っています。

- やり取りはすべてメッセージです。通話や打ち合わせはありません
- 質問15問に答えていただくだけで、文章づくりからお任せいただけます
- 初稿は72時間以内にお届けし、修正2回まで料金に含みます
- スマホでの見やすさを最優先に作ります

構成・文章・デザイン・コーディングに生成AIを活用しています。そのぶん短納期で、文章作成込みの価格にしています。
お渡し前に、スマホ・PCでの表示崩れ、誤字、ボタンのリンク先を確認しています。

医療・整体・美容・健康食品・投資など、広告表現の規制が強い業種のページはお受けしていません。
