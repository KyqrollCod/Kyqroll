# LPの公開手順（購入者向けの雛形）

納品時に〔サイト名〕を差し替え、画面画像を添えて渡す。手順は2026-11時点。画面は変わることがあるので、
初回の納品前に Claude が実際の画面で確かめ、違っていればこのファイルを直す。

---

〔サイト名〕を、無料でインターネットに公開する手順です（所要10分ほど）。

1. 納品したzipファイルをパソコンに保存し、右クリック →「すべて展開」でフォルダに戻します。
2. Netlify（ネットリファイ）の無料アカウントを作ります。メールアドレスかGoogleアカウントで登録できます。
   ※ 先にアカウントを作ってください。登録せずに公開すると、しばらくするとページが消えます。
3. ログイン後の画面で「Add new project（新しいサイト）」→「Deploy manually（手動で公開）」を選びます。
4. 表示された枠に、展開したフォルダ（中に index.html があるフォルダ）をそのままドラッグします。
5. 数十秒で「https://〜.netlify.app」というアドレスが表示されます。これが公開されたページです。
6. スマホでも開いて、申込ボタンが〔窓口名〕につながるかを確かめてください。
7. アドレスの「〜」の部分は、サイトの設定（Site configuration → Change site name）で好きな英数字に変えられます。

内容を変更したいとき: 新しいフォルダを、同じサイトの「Deploys」画面にドラッグすると、同じアドレスのまま差し替わります。
独自ドメイン（例: ○○-kyoshitsu.com）を使いたい場合は別途ご相談ください。
