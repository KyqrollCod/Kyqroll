# 返信の方針と文例

## 方針
- 営業時間（9〜21時）の受信には6時間以内に返す。夜間の受信は翌朝。
- 丁寧語で短く。1通に質問は3つまで。絵文字は使わない。
- 価格・納期・範囲は `docs/spec.md` §2 の範囲で答える。範囲外は「確認してご連絡します」と返し、要判断に上げる。
- 連絡先、外部サービス名への誘導（「LINEで」「メールで」「Driveに」など）を書かない。
  申込ボタンの行き先として購入者の窓口URLを受け取るのは制作内容なので問題ない。
- 送信前チェック: 外部誘導なし／約束した期限が ops-log と一致／価格表と一致／相手の名前・業種の取り違えなし。

## 文例

### 見積り相談（対象業種）
お問い合わせありがとうございます。○○教室様のLP、ぜひお手伝いさせてください。
いただいた内容でしたら、スタンダード（40,000円）の範囲で制作できます。
通話はなく、ご購入後に質問15問へお答えいただき、そこから72時間以内に初稿をお送りします。
もし〔写真がない／急ぎ〕でしたら、〔画像作成／特急〕のオプション（各5,000円）もございます。
ご不明点があれば、このままメッセージでお気軽にお尋ねください。

### 見積り相談（対象外業種）
お問い合わせありがとうございます。大変恐縮ですが、〔業種〕のページは広告表現に関する規制への配慮が
特に必要なため、現在お受けしておりません。せっかくお声がけいただいたのに申し訳ありません。
※送る前に要判断へ上げない。対象外は定型でお断りしてよい。ただし報告には記載する。

### 回答が届いたとき
ご回答ありがとうございます。すべて受け取りました。〔日時〕までに初稿をお送りします。

### 初稿の送付
初稿ができましたので、スマホ版・PC版の画面画像をお送りします。
気になる点は「どこを」「どうしたい」かを箇条書きでいただければ反映します（修正は残り2回です）。

### 納品
修正をすべて反映し、完成版を納品しました。
- 完成ファイル一式（zip）
- 公開手順書
- 画面画像（スマホ・PC）
公開で分からないところがあれば、取引が終わる前にこちらでお尋ねください。

### 納品後（評価のお願い）
このたびはありがとうございました。よろしければ、率直なご感想をレビューで教えてください。
※評価の内容を指定したり、高評価と引き換えに何かを約束したりしない。
