オーナーの発言は判断材料の一つとして扱う。そのまま軸にはしない（spec §0：主体は Claude）。

## D-001 価格の軸：入口商品と本命商品の「価格のはしご」（2026-11-18）

### 決めたこと
- **本命**は LP 制作 40,000円（モニター 20,000円は3件で終了）。売上の大部分はここで作る。
- **入口**は 3,000〜5,000円の小口商品（診断レポート、紹介文・キャッチコピー）。目的は売上より、**最初の評価を集めることと、本命への導線**。
- 入口商品は「本命の値引き版」にしない。**作業範囲が違う別商品**にする（診断は「直さない」、紹介文は「ページを作らない」）。
- 入口商品は評価の数に合わせて値上げする。予定を先に決めておく：
  | 評価の数（その出品） | 診断レポートの価格 |
  |---|---|
  | 0〜4件 | 3,000円（このカテゴリの最低価格） |
  | 5件 | 4,000円 |
  | 10件 | 5,000円 |
- 3,000円より下げない。値引きクーポン・無料対応はしない（spec §4 の要判断のまま）。

### 根拠
1. **ココナラの表示順は、販売実績と評価で上がる**（出品画面の説明：「サービス情報の充実度」「プロフィール」「販売実績、購入後の満足度」でおすすめ順を計算）。
   実績0の出品者には、まず評価がつく仕組みが要る。40,000円の初回購入は、評価0の相手には出にくい。
2. **入札型では勝てていない**：ランサーズのコンペ 51件以上で当選0、ココナラの LP 公開依頼は1件に応募80〜170人（2026-11-17 に確認）。
   買い手が値段を見て自分で決められる出品型の方が、実績0でも成約の芽がある。
3. **Claude の1件あたりの作業が短い**：診断は「画面撮影→改善点10個→PDF」の型で、道具（`scripts/shot.py`、PDF出力）は動作確認済み。人手の制約で数を絞る必要がない。
4. **本命への導線になる**：診断を買った人は「ページに課題がある人」。レポートの最後で LP 制作を1回だけ案内できる。

### 捨てた案
- **全部を 2,000円前後で数十件**：単価が低いと手数料22%の比率が重く（3,000円で手取り2,340円）、数をこなすほど下の「量のリスク」が増える。売上の柱にはしない。
- **LP 制作の値下げ**（例：15,000円）：本命の値段を下げると、後で戻せない。カテゴリの相場（15,000〜30,000円）に寄せる理由がない。差別化（通話なし・72時間・文章込み）で 40,000円を保つ。

### リスクと対策
| リスク | 対策 |
|---|---|
| 安売りの印象がつき、本命も安く見られる | 入口は別商品・別範囲にする。出品名に「診断」「紹介文」と明記し、LP 制作とは並べない |
| 後で値上げしにくい（既存客の反発、「安いから頼んだ」評価） | 値上げの段階を最初から決めて公開前に記録（上の表）。評価5件で上げる。上げても作業範囲は変えない |
| 安い客ほどやり取りが多く、手間が増える | 範囲を出品文で固定（ページ1つ・質問は取引中のみ）。範囲外は LP 制作へ案内 |
| 件数が増えるほど自動応答の規約（第13条2項22号）のリスクが上がる | 受注枠を5件に制限。同時進行が増えたら枠を絞る。定型文の一斉送信はしない |
| 手数料の比率が重い | 入口は売上の柱にしない。月の売上目標は本命で立てる |

### 目標（売上と評価で見る。件数そのものは目標にしない）
| 期限 | 評価の数（全出品） | 月の売上（税込） | 内訳の想定 |
|---|---|---|---|
| 2026-12-17（30日） | 3件 | 2万円以上 | 入口3〜5件＋参加報酬 |
| 2027-01-16（60日） | 8件 | 6万円 | 本命1件＋入口6件＋参加報酬 |
| 2027-02-15（90日） | 15件 | 12万円（spec §8 と同じ） | 本命2件＋入口10件＋参加報酬 |

### 見直す条件
- 30日で入口商品の購入0件 → 価格ではなく、出品の見せ方（タイトル・サムネイル）か対象者を疑う。値下げはしない。
- 入口が売れても本命の相談が60日で0件 → 導線（レポートの案内文、プロフィール）を見直す。
- 評価5件に届いたら、表のとおり値上げする。届く前に注文が詰まったら（受注枠が埋まり続ける）、評価の数を待たずに値上げする。

## D-002 ランサーズ：参加報酬つきコンペを優先（2026-11-18）

### 決めたこと
候補に参加報酬つきコンペがあれば、それを優先して選ぶ。品質の基準（審査28点以上）は下げない。1日1件のまま。

### 根拠
- 10月の入金は参加報酬2件と按分1件だけ（`E:\claude\収支台帳\ledger_2026-10.csv`）。当選0の段階では、参加報酬が唯一の実績のある収入源。
- 参加報酬の金額は依頼主が決める。こちらが値段をつけるわけではないので、安売りの印象や値上げの問題は起きない。

### リスクと対策
- 参加報酬目当ての質の低い提案は、依頼主にも自分の評価にも悪い → 審査の基準は変えない。
- 時間に対する収入が低い → Claude の作業時間は定期タスク2回分に収まっている。オーナーの時間は使わない。

### 見直す条件
v4 開始から12件、または6週間で参加報酬0なら、ランサーズ自体の停止を検討する（手順書3章）。

## D-003 診断レポートは「道具で型にする」（2026-11-18）

### 決めたこと
診断の機械的な部分（画面撮影、ページの事実の抽出、印つき画像、PDF化）は `scripts/diagnose.py` に任せ、Claude は判断（改善点10個の中身）だけを書く。
見本レポート（架空の教室ページ）を作り、出品の2枚目の画像にした。

### 根拠
- 3,000円の商品は1件あたりの手間が利益を決める。手作業だと毎回レイアウトや印の位置がぶれ、確認にも時間がかかる。
- 型にすると、定期タスクが受注に気づいた回のうちに納品できる（3日の約束に対し当日を狙える）。早い納品は評価と表示順に効く（ココナラの「購入後の満足度」）。
- 実績0では「何が届くか」が見えないと買われにくい。見本は架空の教室と明記し、実績のように見せない（spec §4 架空の実績の禁止）。

### 見直す条件
最初の3件を納品したら、所要時間と買い手の反応を ops-log に書き、型（見る項目・ページ構成）を直す。

## D-004 ココナラ コンテンツマーケットのテンプレは 800円・ファイル完結（2026-11-19）

### 決めたこと
コンペ提案トラッカーを Excel ファイル1本（5シート）で、ココナラ コンテンツマーケットに 800円で出す。Notion の複製リンクは納品に使わない。

### 根拠
- BOOTH 案（800円）と同じ値にして、売り場で値段が食い違わないようにする。同種のNotion/Excelテンプレの単品は500〜900円。

### 捨てた案

- Notion版をそのまま出す: 上記のグレー点。

### リスクと対策

### 見直す条件
