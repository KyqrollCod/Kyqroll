# 仕様：ココナラ「ヒアリング不要・72時間納品」講師・コーチ・教室向けLP制作

この事業の仕様はこのファイルだけに書く。CLAUDE.md とスキルはここを参照するだけにする。
最終更新: 2026-11-16（採用決定: 2026-11-16）

## 1. 事業の要点
- 売り場: ココナラ（出品型）。公開依頼への提案は補助的に使う。
- 対象: 個人の講師・コーチ・教室（ピアノ・英会話・書道・料理・プログラミング教室、キャリア/ビジネスコーチ、
  オンライン講座など）。目的は「体験・無料相談の申込」。
- 対象外（受けない、または要判断）: 医療・治療院・整体・美容・健康食品・サプリ・投資・副業塾・
  恋愛/占いの効果保証。薬機法・医療広告ガイドライン・景品表示法・金融関連規制の表現リスクが高いため。
- 差別化: 通話ヒアリングなし（トークルームの質問15問に答えるだけ）、72時間で初稿、修正2回込み、
  AIっぽくないデザイン（persona-lp / unslop の手順）。
- 作業者: Claude が一貫して担当する（制作・出品・返信・納品・報告）。オーナーは定期報告を読む。

## 3. 納品物と公開方法
- 納品物: `index.html` 一式（CSS・画像込みのフォルダ）をzipにしたもの、公開手順書（PDF/テキスト）、スクリーンショット（スマホ・PC）。
- 申込ボタンの行き先は購入者の既存の窓口（LINE公式、Googleフォーム、予約サイト、メール）。
  フォームの裏側（サーバー）は作らない。
- 公開は購入者自身が行う。手順書は無料の静的ホスティング（例: Netlify Drop にフォルダをドラッグ）向けに書く。
  公開代行のために購入者のアカウント情報を受け取らない。
- 要確認（初回の出品作業時に確かめて、このファイルを更新する）: ココナラの納品で添付できるファイル形式と容量、
  タイトル・本文の文字数上限、Netlify Drop の現状。

## 4. 権限（オーナーの決定 2026-11-16）
オーナーは、出品の公開と返信の送信を Claude に任せた。定期報告をオーナーが読むことで確認とみなす。

**事前承認なしで Claude が行い、報告に記載するもの**
- 出品の作成・編集・公開・一時停止、出品画像（サムネイル）の作成
- トークルーム・見積り相談・DM・公開依頼への返信と提案（§2 の価格表の範囲内）
- 制作、納品、修正対応、レビューへの返信
- このリポジトリ内の制作物・記録の更新（commit/push/PR/merge）

**「要判断」として報告に上げ、オーナーの返事があるまで実行しないもの**
- キャンセル・返金・値引き・価格表の変更・無料対応
- お金がかかる操作（広告、有料プラン、有料オプション、ドメイン購入など）
- §1 の対象外業種の依頼を受けるかどうか、規約や法令に触れそうな依頼
- アカウント設定、本人確認、振込申請、退会、パスワードの変更
- クレーム・紛争・法的な請求への対応

**絶対にしないもの**
- ココナラ外への誘導や連絡先の掲示（メール・LINE・SNS・Google Drive などの共有を含む）。ココナラ規約第18条、禁止行為一覧
- 架空の実績・お客様の声・レビュー、虚偽の表示（規約第18条1項5号）
- 購入者の情報を取引の目的以外に使うこと（規約第18条1項3〜4号）
- 他人の著作物・商標・写真の無断使用、実在の他社LPのコピー
- アカウントのパスワードをチャット、ファイル、環境変数に書くこと

## 5. 規約上の論点（2026-11-16 に利用規約の本文を確認済み）
- 第13条2項22号「当社が認める場合を除いて…自動的に応答する等の機能を有する装置、ソフトウェア、アルゴリズム等を利用する行為」は禁止。
- 第6条2項「当社サービスの利用は、利用会員自身が行うものとし」。第74条2項はパスワードの第三者への貸与を禁止。
- 対応方針: ログインはオーナー本人が自分のPCのブラウザで行う。Claude はそのブラウザを
  オーナーの道具として操作し、パスワードを受け取らない。返信を自動送信する前に、運営へ問い合わせて
  第13条2項22号の「当社が認める場合」に当たるかを確認する（文案: `docs/coconala/inquiry-to-coconala.md`）。
  運営から「不可」の回答が来たら、返信の送信方法をオーナーと決め直す。
- 本人確認、出品者登録、振込口座の登録はオーナー本人が行う（売上金の申請には本人確認が必須）。

## 7. 報告（オーナーの確認はこれで満たす）
