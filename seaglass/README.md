# Seaglass — 15秒ループ（Clear Horizon の別案）

![Contact sheet](contact-sheet.jpg)

[Clear Horizon](../clear-horizon/) と同じ色とテーマ（海・空・風、参考画像の白・アジュール・ターコイズ・深い青・ラベンダー・淡い黄色）で作った、図形主体の 15 秒シームレスループです。2 拍ごとに、ひとつのモチーフだけの静かな画面と、図形があふれるコラージュをビートで切り替えます。

- **[`seaglass.mp4`](seaglass.mp4)** — 完成版。1920×1080 / 60p / H.264 + AAC 320kbps / 15.000 秒 / -15 LUFS。ループ再生でつなぎ目なく回ります
- **`index.html`** — エンジン本体。ブラウザで開くとリアルタイム再生・スクラブができます
- **`render.mjs`** — 書き出しスクリプト

タイトルの「シーグラス」は、浜辺に打ち上げられるすりガラスのかけらのことです。アクア、ターコイズ、ラベンダーという色がそのままこのパレットです。

## 構成（96 BPM × 24 拍 = 12 シーン × 2 拍）

| # | 時間 | シーン | 種類 | 内容 |
|---|---|---|---|---|
| 1 | 0.00 | SUN | 単体 | 黄色い太陽、アクア、ラベンダーの円が回りながら重なり、リングが広がる |
| 2 | 1.25 | BEACH | バースト | 約 100 個の図形が中心から外へポップし、風下へ流れる |
| 3 | 2.50 | WAVE | 単体 | ターコイズの三日月が 2 段階のイージングで巻き込む（波頭） |
| 4 | 3.75 | SKY | バースト | アジュールの地に斜めのバーが流れ、縞の入った半円の太陽が昇る |
| 5 | 5.00 | RIPPLE | 単体 | しずくが 1 滴落ちて、水面の線と波紋、泡が広がる |
| 6 | 6.25 | SUNCATCHER | バースト | カット面のあるガラスの菱形が 1/4 回転ずつ回り、左右対称に並ぶ |
| 7 | 7.50 | CHIME | 単体 | 糸で吊られたガラス玉が風に揺れ、風の線が横切る |
| 8 | 8.75 | DEEP | バースト | 青い水中へ。光の柱、泡とかけら、横切る魚 |
| 9 | 10.00 | SAIL | 単体 | 1 本の波に乗る三角の帆 |
| 10 | 11.25 | WIND | バースト | ターコイズの地に突風のバーときらめき |
| 11 | 12.50 | GLINT | 単体 | 四芒星が 1 拍ごとに回り、点が放射状に散る |
| 12 | 13.75 | FINALE | バースト | 最後のコラージュが中心へ流れ込み、1 の太陽の円になってループ |

- **図形の意味**：円は太陽や泡、三日月は巻き込む波、カット面の菱形はシーグラス、星と十字はきらめき、三角は帆、波線は水
- **重なり**：淡い青とラベンダーの図形は乗算で重ねるので、重なった部分がパレットの中の深い色になります。黄色は乗算に入れず、緑に濁らないようにしています
- **カット**：すべてビート上のハードカットです。図形はオーバーシュート付きでポップし、コラージュは中心から外側へ時間差で現れます。最終シーンの終わりは 1 のシーンの最初のフレームと同じ構図なので、ループ点もマッチカットになります
- **音**：96 BPM、D メジャー。各カットにキック、マリンバ、スタッカートのベースが乗ります。バーストでは泡がはじける音とウーッシュ、単体シーンにはそれぞれ固有の音（太陽のチャイム、波のスウィープ、しずく、ガラスのベル、帆、きらめきのグリッサンド）が付きます。DEEP の 2 拍だけミックスが水中のようにこもります

## 参考にした動画から取り入れたこと（模倣はしていません）

- 単体モチーフと図形のバーストをビートで交互に切り替える構成と、図形の重なりで色が混ざる表現
- 斜めに流れるバーでスピード感を出すこと
- 水面、波紋、泡、光の柱

形の語彙（シーグラスの菱形、吊られたガラス玉、しずくと波紋、帆など）と色、シーンの内容は、参考画像の海辺のテーマから起こしています。

## シームレスループの検証

- フル書き出しのフレーム 0 と、単独で描いたフレーム 900 は全画素が一致しました
- 音は 3 周分をレンダリングして中央の 1 周を使っています。ループ末尾 3 秒と前の周の差は 2e-6 程度で、つなぎ目にクリックは出ません
- 速く動く 2 シーン（SKY、WIND）は、モーションブラーのサンプル数を 6 から 16 に増やしています

## After Effects で編集する

**[`ae/Seaglass.jsx`](ae/Seaglass.jsx)** を After Effects で実行すると、このループがネイティブのシェイプレイヤーで組み上がります。.aep は Adobe の非公開のバイナリ形式なので直接は書き出せません。そのためスクリプトを実行して、AE 自身にプロジェクトを作らせる方式にしています。

1. `seaglass/` フォルダごとダウンロードします（`ae/audio/` と `seaglass.mp4` を相対パスで読み込みます）
2. After Effects で **ファイル > スクリプト > スクリプトファイルを実行…** を選び、`seaglass/ae/Seaglass.jsx` を指定します
3. プロジェクトに「Seaglass」フォルダができ、メインコンプが開きます。あとは **ファイル > 保存** で .aep にできます

After Effects 2019（16.0）以降が必要です。JavaScript エクスプレッションエンジンと `createPath()` を使うためです。

| 中身 | 内容 |
|---|---|
| メインコンプ `Seaglass` | 1920×1080 / 60fps / 15 秒。12 シーンのプリコンプ（各 2 拍 = 1.25 秒）を並べ、シーン名のマーカーを付けています |
| シーンのプリコンプ `01 SUN` 〜 `12 FINALE` | シェイプレイヤー、ヌル、平面で合計 409 レイヤーです。図形はすべてベクターなので、色はフィルの色を変えるだけで変わります |
| キーフレーム | 元のアニメーションカーブを毎フレームサンプリングし、ずれが 0.1px 以内に収まる最小限のリニアキーまで間引いています（合計約 2 万）。ビートで値が戻るところは停止キーにしています |
| エクスプレッション | 流れ続ける動き（SKY と WIND の帯、コラージュの波線、帆の波、鳥の羽ばたき、きらめき）は短いエクスプレッションです（159 個）。数値を書き換えれば、速さや振幅を変えられます |
| 描画モード | 乗算で色を混ぜている図形はレイヤーの描画モードが「乗算」、DEEP の光の柱は「スクリーン」です。乗算の図形は色ごとにレイヤーを分けています（1 レイヤーにまとめると、重なりの色が元と変わるため） |
| ヌル | コラージュのズーム（`Zoom`）、サンキャッチャーの 5 つのクラスター、チャイムの振り子（`Pendulum` と `Orb`）の動きはヌルが持っています |
| モーションブラー | すべてのレイヤーでオン、シャッター角 180° です。AE が計算するので、元の書き出しと完全に同じブラーにはなりません。シーンの切り替えはハードカットです |
| レイヤーのラベル色 | ラベルの色でレイヤーの種類がわかります。乗算はラベンダー、スクリーンはイエロー、ヌルはレッド、背景の平面は濃いグリーンです |
| 音声 | [`ae/audio/seaglass.wav`](ae/audio/seaglass.wav) は完成版と同じミックスです。これをメインコンプに置き、小節ごとにマーカーを付けています。`ae/audio/stems/` にはステムが 4 本（drums、bass、music、fx）あります。ステムはミックスと同じゲインで書き出しているのでレベルは揃いますが、マスターのコンプレッサーがステムごとにかかるため、足してもミックスと完全には一致しません |
| ガイドレイヤー | `seaglass.mp4` を、非表示のガイドレイヤーとして一番上に置いています。比較したいときに表示してください |

### 検証

手元に After Effects がないため、AE のスクリプト用オブジェクトモデルを模したモック（[`ae/mock-ae.mjs`](ae/mock-ae.mjs)）でスクリプトを実行しました。このモックは、未知のマッチネーム、値の次元の誤り、範囲外の列挙値をエラーにします。できたプロジェクトを AE の合成ルールで描画し、元のキャンバス版と全 900 フレームを比べました（[`ae/verify.mjs`](ae/verify.mjs)、両方ともモーションブラーなし）。AE のルールとは、レイヤー順、親子関係、アンカー・位置・スケール・回転、シェイプグループの重なり順、描画モード、停止キー、エクスプレッションのことです。平均の差は 255 階調中 0.04 で、差が出たのはアンチエイリアスのかかる縁だけでした。実際の AE では、ラスタライザーの違いから縁がわずかに変わります。

### 作り直すとき

```bash
node ae/build.mjs                                # シーン → ae/Seaglass.jsx（キーの間引きとエクスプレッションの自己チェック付き）
node ae/verify.mjs --all                         # モックの AE で実行して、元の映像と全フレーム比較
FFMPEG=/path/to/ffmpeg node render.mjs --ae-audio    # ae/audio/ の音声とステム
FFMPEG=/path/to/ffmpeg node render.mjs --prores      # 完成版に加えて ProRes 422 HQ のマスター → out/seaglass-prores.mov（約 270 MB）
```

## 書き出し

```bash
cd seaglass
npm install
FFMPEG=/path/to/ffmpeg node render.mjs          # → out/seaglass.mp4（4ワーカーで約1分）
```
